# Library_Management_System
A web-based Library Management System built using Java, JSP, Servlets, JDBC, and MySQL to manage books, members, book issuance, and returns.

# Library Management System

A Java-based web application designed to simplify library operations and manage book inventory efficiently.

## Features
- Add, update, view, and delete books
- Manage library members
- Issue books to members
- Track issued and returned books
- Monitor available book copies
- Dashboard displaying library statistics

## Technologies Used
- Java
- JSP & Servlets
- JDBC
- MySQL
- HTML, CSS & Bootstrap

## Learning Outcomes
- Understanding Java web application architecture
- Implementing database connectivity using JDBC
- Working with Servlets and JSP
- Performing CRUD operations
- Managing relational database relationships

## Project Status
Developed as a hands-on Java Web Development project.
